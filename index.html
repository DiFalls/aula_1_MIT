💡 O que é Informática?

Informação + Automática

Campo que estuda o processamento, armazenamento e transmissão de informações por meio de dispositivos eletrônicos e sistemas computacionais — um pilar indispensável na sociedade moderna.

Pilares Principais:

🔹 Entrada: Coleta de dados (teclado, sensor, toque).

🔹 Processamento: Transformação de dados brutos em informação útil.

🔹 Armazenamento: Salvar dados em memória para uso futuro.

🔹 Saída: Exibição do resultado (tela, som, impressão).

⚙️ Tudo é Hardware e Software

🛠️ Hardware

Componentes físicos e tangíveis do computador (o que você pode tocar).

Exemplos: Gabinete, mouse, teclado, monitor, Processador, Memória RAM, Placa de Vídeo, HD & SSD.

💾 Software

Programas e instruções digitais que fazem o hardware funcionar.

Exemplos:

• Sistema Operacional: Windows 11

• Aplicações: Word, Chrome

• Utilitários: CCleaner, Windows Defender

• Programação: VS Code, Python

🖥️ Hardware e Periféricos Básicos

🔌 Placa-Mãe

Conecta e une todos os componentes do computador em um só circuito.

🧠 Processador (CPU)

O "cérebro" do computador: executa todos os cálculos e tarefas do sistema.

⚡ Memória RAM

Armazena dados temporários para acesso ultrarrápido do sistema em uso.

🖼️ Placa de Vídeo

Gerencia e processa a exibição de imagens, vídeos e gráficos na tela.

💽 HD e SSD

Armazenamento permanente para arquivos, fotos e o sistema operacional.

⌨️ Periféricos

Entrada: Teclado, mouse. Saída: Monitor, som. Armazenamento: Pendrive.

🪟 Evolução do Windows

Surgiu em 1985 como interface gráfica sobre o MS-DOS e evoluiu para se tornar o sistema operacional mais utilizado no mundo.

01

Windows 95

Revolucionou ao introduzir a Barra de Tarefas e o Menu Iniciar.

02

Windows XP

Famoso pela extrema estabilidade e interface amigável e colorida.

03

Windows 7

Consolidou alto desempenho com a estética simplificada e visual Aero Glass.

04

Windows 10

Trouxe atualizações automáticas contínuas, múltiplos desktops e Cortana.

05

Windows 11

Design moderno centralizado, maior segurança e alto desempenho.

🪟 Dominando o Windows na Prática

Funcionalidades Básicas

Menu Iniciar: Central de busca de programas, configurações e arquivos.

Barra de Tarefas: Fica embaixo; fixa os programas mais usados do dia a dia.

Explorador de Arquivos: Onde moram suas pastas, documentos e downloads.

⭐ Atalhos Fundamentais

Win Abre o Menu Iniciar instantaneamente.

Win + E Abre o Explorador de Arquivos.

Win + D Minimiza tudo e mostra a Área de Trabalho limpa.

Alt + Tab Alterna rapidamente entre janelas abertas.

💼 Elementos da Área de Trabalho

📌 Ícones

Atalhos visuais diretos para abrir programas, pastas e arquivos rapidamente.

📊 Barra de Tarefas

Contém o Botão Iniciar, barra de pesquisa, ícones fixados e programas em execução.

⚙️ Acesso Rápido

Painel no canto inferior direito para Wi-Fi, volume, bateria, relógio e notificações.

💡 Super Dica: Use o atalho Windows + E para abrir o Explorador de Arquivos em qualquer momento!

⌨️ Desvendando o Teclado

Shift Maiúsculas & Símbolos

Segure para digitar letras maiúsculas temporárias ou símbolos superiores das teclas (ex: !, @, #).

Ctrl Atalhos de Sistema

Tecla base para comandos universais (Ex: Ctrl + C, Ctrl + V).

Alt / AltGr Menus & Caracteres

Alt: Ativa menus. AltGr: Acessa o 3º símbolo da tecla (ex: @, ², ³).

Caps Lock Maiúsculas Fixas

Trava o teclado para digitar permanentemente em LETRAS MAIÚSCULAS.

Backspace / Delete Apagar

Backspace: Apaga à esquerda. Delete: Apaga à direita ou exclui arquivos selecionados.

Enter Confirmar & Linha

Utilizado para enviar mensagens, confirmar ações ou pular para uma nova linha no texto.

🌐 Navegador: Google Chrome

Funcionalidades Básicas

Abas (Tabs): Permitem abrir múltiplos sites na mesma janela.

Barra de Endereço: Serve para digitar links diretos ou pesquisar no Google.

Favoritos (⭐): Salva seus sites preferidos para acesso rápido.

⭐ Atalhos

Ctrl + T Abre uma nova aba limpa.

Ctrl + W Fecha a aba atual.

Ctrl + Shift + T Reabre a última aba fechada por engano (Salva-vidas!).

📝 Bloco de Notas (Notepad)

O Essencial, Sem Frescuras

A ferramenta mais rápida do sistema para anotar textos simples sem formatação.

Excelente para rascunhos rápidos ou para limpar formatações de textos copiados da internet.

⭐ Atalhos

Ctrl + N Cria um novo documento em branco.

Ctrl + S Salva o arquivo de texto.

F5 Insere automaticamente a Data e Hora atual no texto.

⌨️ Atalhos Universais

✂️

Ctrl + C / Ctrl + V

Copiar e Colar: Funciona em navegadores, pastas, documentos e editores de código!

🔙

Ctrl + Z

Desfazer: Apagou sem querer ou errou uma ação? É a sua viagem no tempo instantânea.

🔍

Ctrl + F

Localizar: Encontra rapidamente uma palavra específica num site longo ou arquivo.

💾

Ctrl + S

Salvar: Crie o hábito constante de salvar para nunca perder seus trabalhos.

🛠️ Troubleshooting no Cotidiano

Caso 1: O Pânico da Aba Fechada
Situação: Fechou sem querer a página em que estava trabalhando.
Solução: Pressione Ctrl + Shift + T no Chrome.

Caso 2: A Reunião Surpresa
Situação: Precisa anotar informações rápidas com urgência.
Solução: Win > digite "Bloco" > Enter para abrir o Bloco de Notas instantaneamente.
